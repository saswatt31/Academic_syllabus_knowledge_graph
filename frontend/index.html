Implementation

Four-stage extraction pipeline

The pipeline executes entirely offline using rule-based regular expressions, syntactic triggers, and gazetteer lookup.

1

Entity recognition

ner_extractor.py

Scans course text for codes, instructors, credit counts, outcome markers, and 91 gazetteer topics with character offsets.

2

Relation extraction

relation_extractor.py

Binds entities into six typed relations; canonicalises bare course codes against the corpus header index.

3

Graph construction

build_graph.py

Assembles a NetworkX MultiDiGraph and serialises graph tables into GraphML and relational CSVs.

4

Verification & benchmark

evaluate_extraction.py

Evaluates relation consistency against source text and runs the 10-query benchmark suite.

$ python run_all.py Executes extraction, graph build, evaluation, and benchmark reproduction
